# AETHERLINE — Unreal Engine 5.8

Repo: https://github.com/kam11s/AETHERLINE-UnrealEngine5-HeroShooter

**Updated 2026-09-17 — full C++ source is on this repo.**

1. Download a **new** ZIP from the green **Code** button.
2. Extract to a **new** folder (do not reuse the old extract).
3. Double-click `Aetherline.uproject` → pick **UnrealEditor** → **Always**.
4. Click **Yes** when it asks to rebuild the Aetherline module.
5. Wait. First compile can take several minutes.
6. Press Play.

This is Unreal source, not a packaged .exe.
