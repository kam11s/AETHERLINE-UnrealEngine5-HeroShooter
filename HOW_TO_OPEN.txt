AETHERLINE — Unreal Engine 5
Repo: https://github.com/kam11s/AETHERLINE-UnrealEngine5-HeroShooter

1. Install Epic Games Launcher and Unreal Engine 5.5 (5.6/5.8 ok).
2. Download this folder (GitHub green Code button → Download ZIP).
3. Double-click Aetherline.uproject
4. If asked, pick Unreal 5.5+ and let it compile.
5. New Level (Empty) → place actor ALArenaBuilder + PlayerStart
6. Save map Content/Maps/L_OrionSpire
7. Project Settings → Maps & Modes → Game Default Map = L_OrionSpire
   GameMode Override = ALGameMode
8. Plug in any controller, then press Play.

Keyboard: WASD, mouse look, LMB fire, Space jump, Q/E, F ult, 1-6 hero.

Controller (Xbox, PlayStation, Switch, Steam Input):
  Left stick move | Right stick look | RT fire | A jump
  LB ability Q | RB ability E | Y ultimate | D-pad change hero
